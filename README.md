# Pink Bunny Itachi Shrine

Public GitHub Pages site for a soft pink bunny-themed Itachi fan shrine, original pixel art, and small web experiments.

## Privacy

This repository is intentionally public. It contains no real name, personal email, location, private diary material, credentials, or other personal details.

## Site files

- `index.html` — homepage
- `shrine.html` — Itachi fan shrine
- `pixel-art.html` — original pixel art
- `favorites.html` — broad public-safe interests
- `links.html` — optional public links
- `styles.css` — styling
- `app.js` — tiny interactive touches
- `404.html` — custom missing-page screen
- `assets/` — original pixel decorations
