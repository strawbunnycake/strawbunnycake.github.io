# Pink Bunny Itachi Shrine

A soft pink bunny-themed Itachi fan shrine with original pixel art and small web experiments.

## Site files

- `index.html` — homepage
- `shrine.html` — Itachi fan shrine
- `pixel-art.html` — original pixel art
- `favorites.html` — favorites
- `links.html` — links
- `styles.css` — styling
- `app.js` — tiny interactive touches
- `404.html` — custom missing-page screen
- `assets/` — original pixel decorations
